# BhumiLipi-v1

**AI-Powered Land Fraud Detection and Verification Platform for Bangladesh**

BhumiLipi is a LandTech Hackathon project designed to improve land ownership transparency, identify potential fraud risks, and make land information easier to verify.

## Key Features

- **Digital Land Identity:** A unique digital identity for every land parcel.
- **Land Fraud Detection:** Identify potential inconsistencies and suspicious land records.
- **Ownership Verification:** Support land ownership verification.
- **Transfer History:** Track land ownership and transfer records.
- **QR Code Verification:** Enable quick access to land information.
